# Chroma

**Group 08 · IAAC MaAI · AI Methods hackathon, 16–20 November 2026**

> Take a photo of a place in Barcelona (a market, a street, a beach, the mountains, the metro, the airport) and hear its soundscape.

An autoencoder learns a map of city sounds. The app reads the photo, finds the place type, and the model returns the real sounds that fit it.
